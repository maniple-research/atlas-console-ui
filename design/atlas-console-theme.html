Fig. 02Brand mark

Three rotated squares.

Maniple is marked by three nested rotated squares — a reference to the three boards of the game Azad in Iain M. Banks's The Player of Games. Use the Full variant by default. Fall back to Compact only when Full becomes illegible — typically below ~28px, where the three frames collapse into noise. Medium is a transitional variant; reach for it rarely. Stroke color inherits from currentColor; the inner diamond uses --accent.

Full · default
28px and up

Three frames at 0°, 22.5°, 45°. Default for every surface — hero placements, page headers, navigation, splash screens.

Compact
below 28px

Fallback only. Single thick frame, enlarged inner. Favicons, 16px nav glyphs, small chips where Full collapses into noise.

Medium
rarely

Transitional variant — single frame at standard stroke. Reach for it only when Compact's thicker stroke reads heavy and Full is still illegible.

Specimen
spec sheet only

Four-frame construction reference. Print specs and brand documentation; never used in product.

Wordmark lockup. The large size pairs the Full mark with the wordmark; the smaller sizes fall back to Compact where Full would be illegible. The trailing period is always --accent; the glyph color inherits currentColor so the lockup tracks with surrounding text color.

Fig. 13Row-list

Rich rows, not a table.

.data-table works when every row has the same shape across aligned columns. When each row is its own little object — title + chips + multi-line meta + value — the table breaks down. Use .row-list with .row .main and .row .balance.

Fig. 17Spinners

Three motions, one mark.

Indeterminate loading. Each spinner reuses the brand-mark geometry — same nested-squares system as Fig 02, animated. SMIL is baked into each symbol so the motion plays without CSS or JavaScript. Pick the variant whose feel matches the wait: orbit for active/mechanical, pulse for steady/calm, dwell for considered/deliberate (the most on-brand). Color inherits via currentColor + --accent.

Orbit

Three layers spinning in alternating directions at different speeds. The contrary motion reads as a layered mechanism.
